기기 승인 미확인

앱 설치와 서버의 기기 승인은 서로 다릅니다. 설치만으로 보호 자료 접근 권한이 생기지 않습니다.

로그인 후 등록 기기의 서버 승인 상태를 확인할 수 있습니다. Release A에서는 기존 메모 읽기·변경·복원이 10단계 인증 계약으로 계속 동작하며, 요청별 기기 서명 강제는 Release B에서 적용합니다.

새 기기는 승인 대기로 등록됩니다. 최초 승인은 관리자의 별도 승인이 필요하며, 이후에는 승인된 기기에서 다른 기기를 승인할 수 있습니다.

등록된 공개 식별자는 이번 화면에서만 선택합니다. Release A의 기기 상태 표시는 기존 메모 접근 권한을 대신하지 않습니다.

    설치 기능을 지원하지 않는 환경에서도 일반 웹사이트로 이용할 수 있습니다.

    오프라인에서는 보호 자료를 읽을 수 없습니다. 연결 후 다시 확인하면 재인증이 필요할 수 있습니다.
